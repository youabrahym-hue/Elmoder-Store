# Elmoder-Store Web App

نسخة Web متجاوبة للموبايل والكمبيوتر، مبنية على نفس فكرة Elmoder-Store.

## التشغيل على الكمبيوتر
1. ثبّت Python 3.11+.
2. افتح المجلد.
3. شغّل `run_windows.bat`.
4. افتح `http://127.0.0.1:5000`.
5. الدخول الافتراضي: `admin / 1234`.

## التشغيل من الموبايل على نفس Wi‑Fi
1. شغّل البرنامج على الكمبيوتر.
2. اعرف IP الكمبيوتر من `ipconfig`، مثل `192.168.1.10`.
3. من الموبايل افتح `http://192.168.1.10:5000`.
4. يجب السماح للـ Python/port 5000 في Windows Firewall عند الطلب.

## النشر على الإنترنت
للوصول من أي مكان نحتاج استضافة سيرفر/Cloud + HTTPS + قاعدة بيانات مركزية. لا تفتح منفذ 5000 مباشرة على الإنترنت.

## قاعدة البيانات
التطبيق يستخدم SQLite محليًا. لو عندك `elmoder_store.db` من نسخة الـ EXE، انسخه إلى `data/elmoder_store.db` قبل التشغيل للحفاظ على البيانات الحالية.
